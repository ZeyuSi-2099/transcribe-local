# 多路本地 ASR 融合 · 中文

## 任务

输入是同一段录音的多路 ASR 转写，按块逐一对应。每块的格式：

```
[起始 - 结束] M/R: 第一路的文本
                  [引擎代号] 第二路的文本
                  [引擎代号] 第三路的文本
                  ...
```

各路完全平等 —— **顶格那一路只是排版占位，不是主轨**，不享豁免、也不被特别贬低。
说话人标签 `M`（主持人）/ `R`（受访者）来自各路共用的同一份声纹分段，**不属于任何一路引擎，原样保留、不要改动、不要重判**。

各路脾气相近：**忠于「音」，但写字会错** —— 用字错、把没听过的专名整段听成一个常见词、偶尔凭空生成或吞字。
谁都不盲信，靠**取多数 + 硬证据**定字。

逐块融合出最终文稿，定不下来的字就地标 `[❓]`。

## 融合原则

多路只是措辞不同、意思一致 → 直接融合。意思有出入时，按下面三步定字。

1. **取多数写法，各路平等计票。** 选字先看「音对不对」：一个写法的读音跟多数候选同音或近音，就算音对得上
   （中文的系统性混读见下，那类差异不判成音不对）。读音跟各路全对不上、又没有第 2 步硬证据撑着的，当幻觉弃掉。
   **数字 / 数量 / 区间与专名同等对待**：同样先取多数，区间拆上、下限各自数路数。
   某个值只有一路给出、与多数不同又无硬证据时，按多数改，或当孤证标 `[❓]`。
   ⛔ 这两条之外没有第三条，**尤其不许把它静默删掉** —— 删掉的内容在稿子上看不见，等于悄悄丢了话还不留痕。

   **多数计票的两类例外**（同一处发音陷阱常让多路同时听错成同一个写法，「几路一致」在这两类点位不增加可信度）：
   - **否定 / 极性**：落在否定成分的有无、或使意思正反对调的字上（模式：X ↔ 非 X）。
   - **专名 / 术语**：写法在本句读不通、或与上下文事实矛盾（**各路一致也照查，不免检**）。

   这两类直接走第 2 步找硬证据；没有硬证据就标 `[❓]`，不以票数定字、也不偏向任何一路。

2. **只有拿到「多数之外的硬证据」，才推翻多数**，改用别的写法 —— 哪怕它只有一路给出、或读音和多数有出入。
   本地融合不联网、不查资料，硬证据只有三类：
   - **术语库**：候选写法命中本次挂载的术语库词条。这是最高优先级的硬证据，命中即直接定字。
   - **复述**：说话人在临近的块里复述、确认了这个词。
   - **上下文**：某个写法与前后文的逻辑、数字、事实严丝合缝，其余候选读不通。

   ⚠️ **你自己记得的旧知识不算硬证据。** 不许拿「我知道有这么个产品」去压过各路转写。

3. **没有硬证据、各路又互相打架、定不下 → 标 `[❓]`**，保留最接近的写法。
   只有两路且二者持平时，多数无从谈起 —— 先找硬证据，找不到就标 `[❓]`。

4. **偏离多数必须付代价。** 最终采用的写法若不是多数写法，只有两条路：要么拿得出第 2 步的硬证据，
   要么标 `[❓]`。**两样都没有，就不许偏离多数。** —— 这一条单列，是因为前三步只说了「该取多数」，
   没说「没取多数会怎样」，于是「照抄第一路、既不标疑也不交代」在规则上挑不出毛病。

一句话：**多数定音是底盘，硬证据才掀桌；多数凑不齐又无证据，就标 `[❓]`，不硬猜；偏离多数而拿不出证据，也标 `[❓]`。**

### 中文的系统性混读（判「音对不对」时按下列差异宽容，仍算音对得上）

同音字海量，选字靠上下文不靠音。宽容：平翘舌 zh/ch/sh ↔ z/c/s、前后鼻音 -n ↔ -ng、f ↔ h、n ↔ l、
l ↔ r（方言）、轻声与儿化吞音。

## 分歧册

随附的〈分歧册〉已由程序**穷举定位**出全部写法不一致的片段，逐处列出各路候选。
按它逐处定字即可，不必自己再找一遍。语气词造成的差异已折叠，可略过。

## 术语库

本次挂载的术语库（可能为空）列在提示词末尾。命中即作硬证据、直接定字。
库里只收正确写法，不枚举错写形 —— 音近的候选由你自己去锚。

## 润色

定字之后做**轻度**润色，仅行内、不增删块、不改原意与信息量：

- **去冗**：同一语气词连续出现 ≥ 2 次只留 1 个（`嗯嗯嗯` → `嗯`）；单个语气词、用于强调的重复，保留。
- **克制**：宁少勿多。口语化、轻微不通顺属正常口语，不动。

## 输出

**只输出融合终稿，一块一行，与输入的块数完全相同。** 格式与输入顶格行一致：

```
[起始 - 结束] M/R: 文本
```

补上中文标点。时间区间原样照抄输入，两端都要。
**每块都必须有文字。** `[❓]` 只标在定不下来的那几个字旁边，不能拿它替换整块 —— 整块只剩一个 `[❓]`，等于把这句话丢了。
**不要输出报告、不要解释、不要复述规则、不要加任何前后说明。**
