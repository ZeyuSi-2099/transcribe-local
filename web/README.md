# 界面（M3）

界面是一套纯静态前端 + 本机 HTTP 后端：**启动后在浏览器里打开 `127.0.0.1`**。
三个平台都不需要签名公证 —— 装一次、敲一行命令起服务，界面就在浏览器里。

⚠️ 不是在浏览器里跑识别。模型 2.8 G、浏览器里推理要慢好几倍、长音频还得自回归解码，
标签页内存也不够 —— 识别始终在本机的 Python 进程里跑，浏览器只是界面。

桌面外壳（Tauri 把这个 `127.0.0.1` 装进一个窗口）是**远期可选项，不挡发布**：
界面代码是同一份，壳只是换个容器。

尚未开始。M3 之前用命令行入口开发：

```bash
python3 -m transcribe_local run <音频>
```
